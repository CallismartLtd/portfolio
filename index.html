A Glimpse of My Journey

How I started

My passion for web development began in 2018 when I built my first blog using WordPress®. The struggle to find the right plugin for my needs sparked my curiosity—and frustration—which eventually led me to pursue web development alongside my career in electrical engineering.

One of my earliest side projects was a notification bell system for the WordPress admin dashboard. That experience introduced me to the WordPress ecosystem under the hood—and quickly fueled my interest in solving real-world problems through plugins.

Not long after, I started experimenting with service billing systems in WooCommerce. I realized that popular subscription plugins like WooCommerce Subscriptions and WP Swings lacked a true subscription abstraction—they were just recurring orders with no clear separation of services, lifecycles, or associated invoices.

That insight led to the creation of Smart Woo Service Invoicing—a purpose-built WooCommerce® extension that models real-world service subscriptions, automates invoicing, tracks usage, and supports prorated billing. It treats subscriptions as contract-based services, not just repeat orders.

Today, I serve as the CEO of Callismart Tech, where I lead the development of powerful WordPress plugins, custom web applications, and SaaS platforms that empower small and medium-sized businesses. I’m proud to have authored several tools available on the WordPress Plugin Repository, and I continue to build solutions that make complex tasks simpler and businesses more efficient.

My main project today is Smart License Server — a database-agnostic PHP application for privately hosting, licensing, updating and distributing software, WordPress plugins and themes. It started as a WordPress plugin and now runs as a WordPress plugin, a standalone web app and a CLI from one codebase. Along the way I extracted its foundations as Composer packages: DBPrism, Callismart HTTP and Callismart DTO.

My Motivation

My primary motivation is to make technology accessible and useful for businesses that need automation, clarity, and performance—but may lack the resources for full-scale enterprise tools. I aim to build scalable, user-friendly solutions that empower small and medium-sized businesses to focus on growth while I handle the complexity behind the scenes.

Whether it’s building a feature-rich plugin from scratch, fine-tuning performance for large-scale WordPress installations, or deploying serverless logic through Cloudflare Workers, my goal is always the same: simplify the workflow, enhance the experience, and unlock new possibilities through clean, maintainable code.

DBPrism

Type: Composer Library – PHP 8.1+

Write a query once and run it on MySQL, MariaDB, PostgreSQL or SQLite. An intent-based query builder, an optional database layer over native drivers and PDO, schema inspection and migrations — each part works on its own. composer require callismart/dbprism

Callismart HTTP

Type: Composer Library – PHP 8.1+

A lightweight HTTP client that falls back from cURL to fopen or sockets on restricted hosts, signs AWS requests with SigV4 without the AWS SDK, and streams large downloads straight to disk. composer require callismart/http

Callismart DTO

Type: Composer Library – PHP 8.1+

A dependency-free base class for type-safe data transfer objects: dynamic properties, type coercion, allowed-key validation and masking of sensitive values. composer require callismart/dto
